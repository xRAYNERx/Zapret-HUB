# Changelog

## [2.0.4] — 2026-10-04

- **Автозапуск служб в свёрнутом режиме**: исправлена проблема, когда при автозапуске программы в свёрнутом виде (в трее) службы обхода и TG Proxy не стартовали автоматически до ручного открытия окна. Теперь выбранные службы запускаются мгновенно в фоне при старте Windows или свёрнутом запуске приложения.
- **Полная совместимость со Steam и TikTok**: добавлены в список прямых исключений (`list-exclude.txt`) все основные домены Steam/Valve и TikTok/ByteDance. Устранены долгие загрузки страниц магазина/сообщества в Steam и сбои подключения в TikTok — теперь трафик к этим сервисам идёт напрямую через вашего провайдера без вмешательства фильтров DPI.
- **Плавная анимация кнопок питания (Обход, TG Proxy, VPN)**: устранено мерцание и преждевременный сброс индикатора загрузки при включении и выключении. Добавлена блокировка кнопок во время переключения для защиты от случайных повторных кликов.
- **Унификация размера плашек замера пинга в VPN**: выровнен размер плашек пинга в списке серверов: теперь и у подключённого, и у остальных серверов плашки отображаются в едином крупном и аккуратном размере.

## [2.0.3] — 2026-09-28

- **Полноценный TUN-режим (VPN для всей системы)**: работа через виртуальный сетевой адаптер Wintun по умолчанию — абсолютно весь трафик системы (онлайн-игры, Discord, Telegram, любые браузеры, лаунчеры и сторонние программы) автоматически направляется через выбранный сервер без настройки прокси в каждой программе.
- **Замер пинга серверов в реальном времени**: постоянный мониторинг задержки активного подключения каждые 5 секунд с обновлением прямо в системном трее Windows и на карточке сервера. В трее убраны технические коды стран (DE, NL).
- **Встроенный обход Telegram в Zapret из коробки**: в основной список сайтов Zapret добавлены домены Telegram (`t.me`, `telegram.org`, `api.telegram.org`, `web.telegram.org`) для работы веб-версии, ссылок и ботов без VPN.
- **Встроенный Telegram Proxy**: быстрое подключение отдельного MTProto-прокси для Telegram в один клик с главного экрана для ускорения загрузки фото, видео и звонков.
- **Умный раздельный автозапуск служб**: возможность независимого включения автозапуска при старте Windows для обхода Zapret и Telegram Proxy.
- **Бесшовное обновление поверх без переустановки**: обновления накатываются прямо поверх текущей версии в автоматическом режиме без повторного прохождения мастера установки. Инсталлятор автоматически завершает активные процессы перед обновлением и запускает обновлённое приложение. Все личные настройки, выбранная стратегия и подписки гарантированно сохраняются.
- **Стабильные уведомления Windows**: регистрация AppUserModelId для безотказной доставки всплывающих оповещений Windows.
- **Подробная история изменений прямо в приложении**: синхронизация списка релизов с GitHub Releases без ограничений по IP.

## [2.0.2] — 2026-09-28

- **Опция чистой установки в инсталляторе**: этап с опцией очистки старых бинарников и служб без потери пользовательских настроек (стратегии, VPN, списки).
- **Нативное окно автообновления**: автоматическое скачивание инсталлятора с индикатором прогресса и перезапуском.
- **Исправление проверки обновлений**: исключены ложные уведомления и корректно отображается номер текущей версии в интерфейсе.

- **Исправление запуска обхода при обновлении**: устранена блокировка старта обхода на системах, где ранее присутствовала устаревшая системная служба Zapret
- **Синхронизация файлов движка в AppData**: теперь при обновлении приложения все новые стратегии обхода, списки и бинарные компоненты корректно и автоматически обновляются в рабочей директории
- **Повышение стабильности WinDivert**: перед запуском обхода выполняется автоматический сброс зависших сетевых фильтров и корректная очистка старых служб
- **Отказоустойчивый выбор стратегии**: автоматический fallback на доступную рабочую стратегию при отсутствии или повреждении предыдущего файла конфигурации
