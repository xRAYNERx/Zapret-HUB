# Changelog

## [2.0.1] — 2026-09-27

- **Исправление запуска обхода при обновлении**: устранена блокировка старта обхода на системах, где ранее присутствовала устаревшая системная служба Zapret
- **Синхронизация файлов движка в AppData**: теперь при обновлении приложения все новые стратегии обхода, списки и бинарные компоненты корректно и автоматически обновляются в рабочей директории
- **Повышение стабильности WinDivert**: перед запуском обхода выполняется автоматический сброс зависших сетевых фильтров и корректная очистка старых служб
- **Отказоустойчивый выбор стратегии**: автоматический fallback на доступную рабочую стратегию при отсутствии или повреждении предыдущего файла конфигурации

## [2.0.0] — 2026-09-27

- **Полностью обновлённый дизайн**: современный интерфейс Elevated Slate с акцентной темной палитрой
- **Встроенный VPN (VLESS Reality)**: поддержка высокоскоростного подключения VLESS Reality с параллельным замером задержки серверов
- **Раздельное управление автозапуском**: независимые переключатели для автоматического старта обхода Zapret и прокси Telegram при входе в систему
- **Динамический список изменений**: автоматическая загрузка информации о релизах напрямую из репозитория GitHub
- **Улучшенный установщик**: чистая установка и интеграция в системное окружение Windows

- Оптимизация и ускорение работы интерфейса и опроса статусов
- Устранено назойливое окно о падении обхода при штатных действиях и мелких сетевых сбоях
- TG Proxy больше не спамит частыми фоновыми запросами к GitHub
- Удалены неактивные функции и устаревший код

## [1.1.4] — 2026-06-27
